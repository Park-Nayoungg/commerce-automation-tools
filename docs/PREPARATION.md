# 공개용 정리 내역

- 원본 Python 도구 23개와 PyInstaller 설정 2개를 기능별로 분류했습니다.
- 원본 파일명과 사이트별 구현을 유지했습니다. v1/v2가 서로 다른 관리자 페이지를 대상으로 하는 경우가 있어 임의로 삭제하거나 최신판으로 합치지 않았습니다.
- 특정 쇼핑몰 관리자 주소와 계정별 검색 URL을 `config.local.json`으로 분리했습니다. 이 파일은 Git과 공개 ZIP에 포함하지 않습니다.
- 고정된 개인 PC 저장 경로와 주석의 브라우저 프로필 경로를 제거했습니다. 다운로드·내보내기는 기본적으로 `data/` 아래에 저장합니다.
- GIF 변환은 입력·출력 폴더를 인자로 받도록 변경하고, 기존 출력 파일의 덮어쓰기를 방지했습니다.
- 이미지 압축 도구의 용량 표기에서 단위 변환을 두 번 적용하던 오류를 수정했습니다.
- `price_monitor.py`에서 실제 가격 비교 흐름이 사용하지 않는 재고 감시 복사 코드를 제거했습니다. 정의되지 않은 이름이 타입 표기에 사용되어 실행을 막던 부분입니다. 가격 비교·엑셀 표시 흐름은 유지했습니다.
- 별도 대형 프레임워크로 재작성하지 않았습니다. 기존의 업무별 단일 스크립트 구조를 유지했습니다.
- 외부 사이트 UI, 실제 로그인, 운영 상품 수정, EXE 빌드는 이번 정리 과정의 검증 범위에 포함하지 않습니다.

## 라이선스

별도의 이용 허락을 임의로 부여하지 않았습니다. 공개 저장소에서 재사용을 허용할 범위를 결정한 뒤 적합한 LICENSE를 추가할 수 있습니다.
